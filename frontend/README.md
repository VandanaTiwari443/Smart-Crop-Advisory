# 🌱 Smart Crop Advisory System (AgriGuide)

A full-stack MERN web application designed to help farmers and agricultural users make smarter crop decisions based on:

- Soil Type
- Season
- Water Availability
- Land Area
- Budget

The system provides intelligent crop recommendations, estimated profit analysis, fertilizer suggestions, irrigation guidance, advisory history, analytics dashboards, and user profile management.

---

# 🚀 Live Project Goal

To create a real-world agriculture solution that supports better farming decisions, improves profitability, and reduces poor crop selection.
